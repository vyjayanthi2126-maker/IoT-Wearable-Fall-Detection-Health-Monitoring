# IoT-Wearable-Fall-Detection-Health-Monitoring
# IoT-Enabled Wearable System for Fall Detection and Multi-Parameter Health Monitoring for Elderly People

## Project Description

This repository contains the ESP32 source code developed for the proposed IoT-enabled wearable monitoring system.

The system integrates:
- MAX30102 for heart-rate monitoring
- MAX30205 for temperature measurement
- AD8232 for ECG signal acquisition
- MPU6050 for fall detection
- NEO-6M GPS for location tracking
- Blynk IoT for remote monitoring
- Buzzer and LED for local alerts

## Source Code

The main ESP32 program is provided in:

ESP32_Wearable_System_Public.ino

## System Functions

The code performs:
- Heart-rate measurement
- Temperature monitoring
- ECG signal acquisition
- Motion and fall detection
- GPS location tracking
- Health-alert generation
- Blynk-based remote monitoring

## Code Availability

The source code is provided to support reproducibility and technology transfer of the proposed system.
